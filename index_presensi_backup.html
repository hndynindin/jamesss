Metode 1: GitHub Pages (Gratis & Aktif HTTPS)
  1. Buat repositori baru di GitHub (contoh: presensiku-pro).
  2. Unggah berkas index.html ke branch main.
  3. Masuk ke menu Settings > Pages > Branch: main (/root) > Save.
  4. Tunggu 1 menit, web langsung aktif: https://username.github.io/presensiku-pro/.
Metode 2: VPS (Virtual Private Server)
  1. Salin berkas index.html ke direktori web server VPS (/var/www/html/).
  2. Konfigurasi Nginx / Apache untuk mengarahkan ke domain/subdomain Anda.
  3. Pasang sertifikat SSL publik dengan Certbot Let's Encrypt: certbot --nginx.
  4. Akses domain melalui protokol https://absensi.domain-anda.com.
Dilarang Menggunakan Link Lokal:

Sistem pengumpulan otomatis menolak URL seperti localhost, 127.0.0.1, atau IP privat 192.168.x.x. Pastikan tautan yang dikumpulkan sudah online dengan protokol https://.
